# AI-asistent-for-DA

Fналітичний асистент для автоматизації первинного аудиту якості даних, генерації перевірюваних продуктових гіпотез, факторного аналізу спаду метрик та підготовки звітів для керівництва на основі Python, Pandas та Google Gemini API.

---

## 1. Архітектура та ключові принципи

Проєкт побудовано на принципі розділення обчислень та інтерпретації:
* **Всі розрахунки на Python:** уся математика, підрахунок пропусків, пошук викидів за правилом міжквартильного розмаху, групування когорт та факторна декомпозиція виконуються локально за допомогою бібліотек Pandas та NumPy. Модель ніколи не проводить арифметичних дій самостійно.
* **Семантична інтерпретація за допомогою Gemini:** LLM Gemini отримує готові стислі числова висновки у форматі JSON і відповідає виключно за формулювання логічних зв'язків, виявлення бізнес-аномалій та генерацію зрозумілих для людини висновків.
* **Використання створених інструметів:** 
  * Перша функція (Auto EDA) є абсолютно універсальною і працює з будь-якими табличними даними незалежно від тематики.
  * Наступні три функції оптимізовані для продуктової аналітики та SaaS-бізнесу.
* **Динамічне визначення схеми:** модуль автоматично розпізнає цільові грошові показники, часові ряди та категоріальні сегменти без жорсткої прив'язки до імен стовпців, що дозволяє застосовувати код до довільних CSV-файлів відповідної тематики.

---

## 2. Структура проєкту

* `Лабораторна_робота_4.ipynb` — основний робочий блокнот у Google Colab із реалізацією логіки обробки даних, промптів та збереженими результатами виконання.
* `prompts.md` — детальна документація трьох ітерацій промптів (v1, v2, v3) для кожної з чотирьох функцій із порівняльним аналізом отриманих відповідей.
* `README.md` — інструкція щодо налаштування середовища, структури, запуску та обробки крайніх випадків.

## 3. Технологічний стек

* **Мова програмування:** Python 3.10+
* **Обробка та агрегація даних:** Pandas, NumPy
* **Генеративна модель:** Google Gemini API (`gemini-3.5-flash`, `gemini-3.8-flash`) через бібліотеку `google-genai`
* **Джерело даних:** Kaggle API (датасет `bhaskerpaul/sales-and-marketing-dataset`)
* **Середовище виконання:** Google Colab
